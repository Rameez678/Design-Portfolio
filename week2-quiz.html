Overview

An interactive quiz that tests knowledge of web development, such as HTML, CSS and JavaScript. All of the logic is written in plain JavaScript.

Main features

  • Choose a category, a difficulty and how many questions to answer
  • Countdown timer for each question that changes with the difficulty
  • Score tracking with feedback after each answer
  • High scores saved in the browser using localStorage
  • Sound on/off button
