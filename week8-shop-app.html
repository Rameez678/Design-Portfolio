Mobile Shop App

React Native Expo Redux Toolkit React Navigation

Overview

A more advanced mobile shopping app. It loads products from an online API and lets users browse them, save favourites and build a cart.

Main features

  • Products, product details, cart and favourites screens
  • Cart and favourites managed with Redux Toolkit
  • Drawer, tab and stack navigation combined
  • Light and dark theme switch
  • Layout changes for larger screens such as tablets
