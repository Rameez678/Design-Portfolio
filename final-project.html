FINAL YEAR DISSERTATION

Full E-commerce Website

React Vite Tailwind CSS React Router Node.js Express MongoDB AWS Amplify Nodemailer

Overview

For my final year dissertation I builta full online store for designer clothing, trainers and fragrances. It has two parts: a front end (the website people see, built with React and Tailwind CSS) and a back end (a Node.js and Express server connected to a MongoDB database). They talk to each other through a REST API.

Main features

  • Shop page with filters and a grouped or single product view
  • Product pages with sizes, colour options and a "viewed" counter
  • Basket, checkout and order history
  • Liked items (wishlist) saved to the user's account
  • User login with a protected dashboard
  • Search bar across all products
  • Language (English, French, Spanish) and currency (GBP, USD, EUR) switcher
  • "For You" product suggestions and a live-chat helper bubble
  • Contact form that sends a real email using Nodemailer

How it works

The back end has separate routes for users, products, baskets, orders, likes, views and contact messages. The React front end calls these routes to load products, save the basket and place orders. All the data is stored in MongoDB.
