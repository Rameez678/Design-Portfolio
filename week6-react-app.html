Shoe Galaxy

React React Router Vite REST API

Overview

Shoe Galaxy is a multi-page React application. Instead of typing the products into the code, it fetches them live from the Fake Store API, an online REST API.

Main features

  • Several pages (Home, Collection, Product details, About and Cart) using React Router
  • Products loaded from an API with fetch
  • Search box that filters products as you type
  • Shopping cart shared across pages using React Context
  • Custom 404 "page not found" page
